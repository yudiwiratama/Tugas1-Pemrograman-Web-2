# Tugas1-Pemrograman-Web-2

## How to Run This Web App

1. Install docker & docker compose

2. Running With Docker Compose

```bash
sudo docker-compose up -d --build
```

3. Stop / Remove this App

```bash
sudo docker-compose down -v
```
